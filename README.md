# TikTok iOS Mod (BHTikTok++)

Свой твик для TikTok на iOS на основе [BHTikTokPlusPlus](https://github.com/raulsaeed/BHTikTokPlusPlus) (Theos).
Собирается в GitHub Actions на macOS-раннере, поэтому Mac для сборки не нужен.

## Что умеет
- Без рекламы, скачивание видео/HD/фото/музыки, без водяного знака
- Подтверждение лайков и подписок, копирование описания и ссылок
- Прогресс-бар, автопроигрывание, расширенная биография и комментарии
- Смена региона (по умолчанию Казахстан, см. ниже) — для рекомендаций в России без VPN

## Как собрать IPA (GitHub Actions)

1. Форкните репозиторий или создайте свой и загрузите в него эти файлы.
2. Откройте вкладку **Actions** → workflow **Build BHTikTok IPA** → **Run workflow**.
3. IPA берётся из **черновика релиза `tiktok-ipa`** (draft, виден только владельцу репозитория). Загрузите туда **расшифрованный** TikTok IPA
   (например, `gh release upload tiktok-ipa файл.ipa` для существующего черновика или через веб-интерфейс GitHub: Releases → Draft). Поле `ipa_url` можно оставить пустым.
   Поле `display_name` необязательно: если указать, приложение будет называться так.
4. Дождитесь окончания сборки (обычно 15–30 минут при первом запуске, дальше быстрее за счёт кэша).
5. Откройте завершённый запуск и скачайте артефакт **BHTikTok-ipa**. Внутри файл `BHTikTok.ipa`.

Важно: IPA должен быть именно расшифрованным (decrypted), иначе инъекция твика не сработает.
Ссылку на IPA и сам IPA не публикуйте в открытом доступе.

## Как установить IPA на iPhone

Нужен аккаунт Apple ID (для Sideloadly и AltStore) и компьютер для подписи, либо TrollStore для устройств, где он работает.

- **Sideloadly** (Windows/macOS): перетащите `BHTikTok.ipa` в окно программы, введите Apple ID, нажмите Start. На iPhone подтвердите доверие к профилю разработчика в Настройки → Основные → VPN и управление устройством.
- **AltStore** (Windows/macOS): установите AltServer на компьютер, затем через AltStore на iPhone добавьте IPA. Подпись нужно обновлять раз в 7 дней.
- **TrollStore**: если устройство и версия iOS поддерживаются, установка IPA происходит без переподписи.

Перед установкой удалите оригинальный TikTok, если подпись не совпадает.

## Регион по умолчанию: Казахстан (KZ)

- Смена региона включена по умолчанию, регион по умолчанию — **Kazakhstan (KZ, mcc 401, mnc 02)**. Это нужно, чтобы рекомендации работали в России без VPN.
- Значения заданы через `registerDefaults` в `%ctor` файла `Tweak.x`. Они действуют, пока пользователь сам ничего не менял.
- Сменить или выключить регион: в приложении откройте настройки мода (BHTikTok) → раздел **Region**:
  - **Enable Region Changing** — выключатель смены региона;
  - **Regions** — выбор страны из списка (Kazakhstan добавлен в конец списка в `Settings/CountryTable.m`).

## Структура

- `Tweak.x` — основной код хуков и дефолты
- `BHIManager.m/.h` — чтение настроек из NSUserDefaults
- `Settings/` — экран настроек мода
- `.github/workflows/build.yml` — сборка IPA в GitHub Actions
